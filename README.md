# 오프라인 번역기 (Offline Korean–English Voice Translator)

인터넷 없이 동작하는 한영 음성 번역 웹앱(PWA)입니다. 안드로이드 폰의 Chrome에서
"홈 화면에 추가"로 설치하면 앱처럼 쓸 수 있습니다. 첫 실행 때 모델을 한 번 받으면
그 뒤로는 완전 오프라인으로 동작합니다.

## 설치 방법

1. 안드로이드 폰의 Chrome으로 https://grace39237-sys.github.io/offline-translator/ 를 엽니다.
2. Chrome 메뉴(⋮) → **홈 화면에 추가** (또는 "앱 설치")를 누릅니다.
3. 처음 실행하면 모델을 다운로드합니다. Wi-Fi 연결 상태에서 기다려 주세요
   (아래 용량 참고). 다운로드가 끝나면 "오프라인 준비 완료"가 뜹니다.
4. 그 뒤로는 비행기 모드에서도 번역이 됩니다.

## 사용법

- **언어 바**: 위에서 한국어/영어를 고르고, 가운데 ⇄ 버튼으로 방향을 바꿉니다.
- **입력 카드**: 텍스트를 직접 입력하거나 마이크 버튼을 눌러 말합니다.
- **인식 결과 카드**: 인식된 글자가 편집 가능한 칸에 뜹니다. 틀린 부분은 직접
  고친 뒤 **번역** 버튼을 누릅니다.
- **결과 카드**: 번역된 글자가 크게 뜹니다. 🔊 듣기 버튼으로 읽어주고,
  복사 버튼으로 클립보드에 복사합니다.
- **대화 모드**: 마이크 옆의 **대화 모드** 버튼을 켜면 마이크가 계속 듣고 있다가
  말이 끝나면(약 0.9초 침묵) 자동으로 인식→번역해서 화면에 띄웁니다.
  방향은 자동 감지가 아니라 ⇄ 버튼으로 수동 전환합니다.
  상대가 말할 차례가 되면 ⇄를 눌러 방향을 바꿔 주세요.
- **받아쓰기 모드**: 입력 카드 위의 **받아쓰기**를 고르면 말한 내용이 번역 없이
  인식된 글자로만 이어붙습니다. 번역이 필요하면 인식된 글자 아래의
  **번역하기**를 누릅니다. 번역 버튼(입력 글자 번역)은 모드와 관계없이
  지금처럼 원문+번역문을 같이 보여줍니다.
- **최근 번역**: 아래 목록에 최근 번역이 폰 안에만 저장됩니다(최대 30개).

## 첫 실행 다운로드 용량

| 방향 | 음성인식 | 번역 | 합계 |
|---|---|---|---|
| 한국어 → 영어 | Moonshine base-ko ~67MB | Opus-MT ko-en q8 ~123MB | **약 190MB** |
| 영어 → 한국어 | Moonshine tiny-en ~32MB | Opus-MT en-ko q8 ~266MB | **약 300MB** |
| 양쪽 모두 | | | **약 490MB** |

모델은 Hugging Face Hub에서 받아 브라우저 캐시에 저장됩니다.
앱 자체(코드+아이콘+JS 라이브러리)는 약 33MB로 이 저장소에 포함돼 있습니다.

## 사용한 모델 (정확한 ID)

- 음성인식(한국어): `onnx-community/moonshine-base-ko-ONNX`
  (Moonshine base, 62M 파라미터, 양자화 q8) — 2026-11-24부터 기본값.
  tiny-ko는 실폰 테스트에서 인식률이 너무 안 좋다고 보고돼 교체됨.
- 음성인식(영어): `onnx-community/moonshine-tiny-ONNX`
- 번역(한국어→영어): `Xenova/opus-mt-ko-en` (q8)
- 번역(영어→한국어): `teamwon/opus-mt-en-ko-onnx` (q8) —
  Helsinki-NLP/opus-mt-tc-big-en-ko를 ONNX로 변환·int8 양자화해서
  Won 계정(teamwon)으로 Hugging Face Hub에 올린 것 (2026-11-24).
  sepvoc 모델이라 pipeline 대신 수동 generate + tokenizer_target.json
  디코딩으로 쓴다 (`mt.js` 참고). NLLB-200 q8(~894MB)은 2026-11-24에 교체됨.
- 런타임: `@huggingface/transformers` **3.8.1** (v3 고정) + onnxruntime-web
  (둘 다 `vendor/`에 포함돼 있어 CDN 없이 동작합니다)

## 알려진 제한

- **한국어 인식 정확도** (같은 테스트 문장, 5.5초 음성 기준):
  tiny-ko는 2단어 오류("소로티"→"서로 티", "내일"→"매일"),
  base-ko(`onnx-community/moonshine-base-ko-ONNX`)는 구두점 제외하고 완벽했습니다.
  2026-11-24 실폰 테스트에서 tiny-ko 인식률이 너무 안 좋다고 보고돼
  기본값을 base-ko로 바꿨습니다. tiny-ko로 되돌리려면 `asr.js`의
  `ASR_MODEL_KO` 상수 하나만 바꾸면 됩니다.
  인식이 틀렸을 때는 결과 카드에서 직접 고치고 번역하세요.
- **영어→한국어 번역 속도**: Opus-MT q8은 Node 테스트에서 문장당 약 0.5초
  (NLLB는 약 8.9초였다). 다만 5문장 중 1문장("Please send the invoice
  before Thursday.")에서 invoice(송장)가 빠지는 경우가 있다.
- **읽어주기(TTS)**는 폰 내장 음성(Chrome Web Speech API)을 씁니다.
  폰 설정에서 한국어/영어 음성 데이터를 받아 두면 오프라인에서도 읽어줍니다.
  폰에 해당 음성이 없으면 읽기가 안 될 수 있습니다.
- **한 번에 인식하는 말은 최대 30초**입니다. 긴 말은 나눠서 말해 주세요.
- **문장 단위 번역**입니다. 말하는 도중 실시간 동시통역은 안 됩니다.
  말이 끝난 뒤 몇 초 뒤에 번역이 뜹니다.
- 대화 모드의 말 구간 감지는 에너지 기반입니다. 아주 시끄러운 곳에서는
  말이 잘 안 끊길 수 있습니다.

## 기술 메모

- Moonshine 한국어 모델의 `preprocessor_config.json`에는 `processor_class`가
  없어서 transformers.js의 `pipeline()`으로는 토크나이저를 못 불러옵니다.
  그래서 `asr.js`는 모델·토크나이저·특징추출기를 직접 불러 `MoonshineProcessor`를
  손으로 조립합니다.
- transformers.js v3.8.1을 고정했습니다. v4.x에는 인코더-디코더 ASR 모델
  세션을 깨뜨리는 int8 버그가 있습니다.
- GitHub Pages는 COOP/COEP 헤더를 안 보내서 SharedArrayBuffer가 안 됩니다.
  그래서 ONNX 스레드는 1개로 고정했습니다.
